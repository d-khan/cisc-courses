# Integrated Development Environment for Python

For this course, you are free to use any IDE (Integrated Development Environment) of your choice to write and run Python
programs. There is no single required tool—please use the development environment that works best for you.

Personally, I use **PyCharm**, which you can download from the JetBrains website:

<https://www.jetbrains.com/pycharm/>

In addition to an IDE, you will need to have **Python installed on your computer**. PyCharm can be configured to use
your installed Python interpreter when creating and running projects.

Alternatively, you can write Python code using a text editor, such as **VS Code** or **Sublime Text**, and run your
programs directly from the terminal or command line. This approach is recommended only if you are comfortable working in
a command-line environment.

Choose the option that best fits your workflow and learning style. The important part is to develop a consistent
workflow for **writing, running, testing, and debugging Python programs**.

## Please Note

**Do not use online Python compilers as your primary development environment for this course.** While online
environments can be useful for quickly testing small pieces of code, they generally do not provide the complete
development experience expected in this course.

A local development environment such as PyCharm provides important programming tools, including **step-by-step
debugging, variable inspection, package management, project organization, and version control integration**. These tools
become increasingly important as Python programs grow in complexity.

For this course, you are expected to use a local Python development environment so that you become familiar with
development practices and tools commonly used in real-world software development.
