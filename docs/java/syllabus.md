# **Syllabus (CISC-190 Java Programming)**

## **Welcome to the course!**

Welcome to the course! I look forward to working with you this semester. This course is designed to encourage curiosity,
problem-solving, and hands-on learning in a supportive and respectful environment. Do not be afraid to make
mistakes—they are an important part of learning Computer Science.

## **Course description**

This course provides an introduction to programming using Java. Students will learn the fundamentals of programming and
object-oriented programming while developing general-purpose applications and interactive programs. The course is
designed for students majoring in Computer and Information Sciences, as well as anyone interested in learning Java
programming.

## **Course topics**

| Topics                             | Hands-on activities                             |
|------------------------------------|-------------------------------------------------|
| Introduction to Java Programming   | Getting Started with Java                       |
| Java Programming using Methods     | Working with Methods                            |
| Decision statements and loops      | Using Decision Statements and Loops             |
| Single and Multidimensional Arrays | Working with Single and Multidimensional Arrays |
| Polymorphism                       | Applying Polymorphism                           |
| Exceptions                         | Handling Exceptions                             |
| File operations                    | Working with File Operations                    |
| GUI widgets and interactions       | Building Interactive GUIs                       |
| Multithreading                     | Working with Multithreading                     |
