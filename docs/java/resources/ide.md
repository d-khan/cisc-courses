# Integrated Development Environment for Java

For this course, you are free to use any IDE (Integrated Development Environment) of your choice to compile and run Java
programs. There is no single required tool—please use what works best for you.

Personally, I use IntelliJ IDEA Ultimate Edition, which you can download from <https://www.jetbrains.com/idea/>. IntelliJ
IDEA Ultimate is available free of charge to SDCCD students through the JetBrains educational license. To access the
license, create a JetBrains account and register using your SDCCD email address.

Alternatively, you can also write your code in any text editor (such as VS Code, Sublime, or even Notepad++) and compile
it directly from the terminal/command line—but this approach is recommended only if you are comfortable with it.

Choose the option that best fits your workflow and learning style. The important part is writing, compiling, and running
your programs consistently.

**You can also watch the [video](https://www.youtube.com/watch?v=yf_fwwB_ueI&ab_channel=DanishKhan) which shows how to install Java IDE, install JDK and run your very first Java code.** 

__Note about online Java compilers__

Do not use online Java compilers. Professional software developers do not rely on such environments because they lack
essential development tools. In particular, online compilers provide little to no support for step-by-step debugging,
memory inspection, or runtime analysis—features that are critical when learning and working with Java. Additionally,
these platforms do not support proper project structure, build systems, or version control, all of which are standard
practices in industry. For this course, you are expected to use a local development environment that reflects real-world
professional workflows.
