# Integrated Development Environment for C++

For this course, you are free to use any IDE (Integrated Development Environment) of your choice to compile and run C++
programs. There is no single required tool—please use what works best for you.

Personally, I use CLion, which you can download here: <https://www.jetbrains.com/clion/>

Alternatively, you can also write your code in any text editor (such as VS Code, Sublime, or even Notepad++) and compile
it directly from the terminal/command line—but this approach is recommended only if you are comfortable with it.

Choose the option that best fits your workflow and learning style. The important part is writing, compiling, and running
your programs consistently.

__Please note__

Do not use online C++ compilers. Professional software developers do not rely on such environments because they lack
essential development tools. In particular, online compilers provide little to no support for step-by-step debugging,
memory inspection, or runtime analysis—features that are critical when learning and working with C++. Additionally,
these platforms do not support proper project structure, build systems, or version control, all of which are standard
practices in industry. For this course, you are expected to use a local development environment that reflects real-world
professional workflows.
